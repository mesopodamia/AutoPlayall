# AutoPlayAll · 页面连播

## 通用模式（1.1.0）

其他网站点击工具栏 AutoPlayAll 图标，扫描音频播放器和 MP3、M4A、OGG、WAV 等直接音频链接。选择顺序循环或随机不重复后开始。若音源动态加载，请先操作网页加载音源，再点击「重新扫描」；扫描会停止播放并重建队列。

仅识别主文档中已暴露的音频地址，不自动解析私有歌单接口，不支持 iframe、Shadow DOM、Blob/DRM 或 HLS/DASH。世纪音乐网继续自动启用专用适配。以下播放范围和接口说明针对该站适配。

## 安装

1. 如果使用 ZIP，请先解压，保留包含 manifest.json、engine.js、content.js 的完整文件夹。
2. Chrome 地址栏输入 chrome://extensions/ 并打开。
3. 开启右上角「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择包含 manifest.json 的 extension 文件夹（ZIP 解压后直接选包含该文件的文件夹）。
5. 打开或刷新 https://www.4c44.com/mp3/hekkmd.html ，如出现验证请手动完成。

## 播放

网页右下角会出现「AutoPlayAll」面板。点击「开始播放」。原网站播放器会暂停，插件独立播放此页面的歌曲。

- 本次保存页面包含《天黑黑》和32首推荐音乐，合计33首；网站推荐变化时，以刷新后显示的数量为准。
- 顺序循环：当前歌曲在前，其余按页面顺序播放，列表结束后从头开始。
- 随机不重复：每轮所有歌曲各播一次，跨轮避免紧接着重复同一首。播放中切换模式会重新组织剩余队列。
- 音频控件可以暂停、继续、拖动进度和调节音量。「下一首」切歌，「停止」终止队列。
- 「收起」后继续播放；展开可查看队列。保持网页标签打开，刷新会重置队列。
- 队列固定为最初页面的歌曲，不会自动把下一首页面的推荐歌曲加入队列，不会遍历整站或歌手全部歌曲。

## 常见问题

如果浏览器拦截自动播放，点击面板中的原生音频播放按钮继续。不要同时操作网站原播放器。

获取音源或加载失败时自动跳过；连续整队列失败后停止，避免无限重试。先确认网站验证有效、原站音源可正常播放，然后停止并重新开始。接口使用电脑本地时间生成网站要求的分钟级 key，请保持系统时间准确。

面板只会在检测到本站歌曲链接或播放器的页面出现；安装或更新插件后需要刷新原先打开的网页。

## 权限与验证情况

通用模式通过 activeTab 和 scripting 在点击工具栏图标后访问当前页，无所有网站永久访问权限。世纪音乐网保持限定域名自动运行，通过本站接口获取音源。播放时浏览器会连接音源服务器；插件没有追踪或开发者数据接收服务。

已根据保存的真实 HTML/播放器脚本验证歌曲提取、请求参数，以及播放引擎的自动切歌、随机不重复、停止和失败处理。尚未在已安装插件的真实 Chrome 页面完成音频端到端验证。
