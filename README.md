# AutoPlayAll · 页面歌曲连播

识别网页音频并连续播放的浏览器扩展，支持顺序循环和随机播放。通用模式扫描页面中的音频播放器与直接音频链接，同时保留世纪音乐网专用适配。

以下网站中，世纪音乐网保留专用适配；其余网站可尝试通用扫描，能否识别取决于页面是否暴露音频地址，尚未逐站验证。

- [世纪音乐网](https://www.4c44.com/)
- [无名音乐网](https://www.mvmp3.com/)
- [听听盘](https://www.ttpan.cc/)


使用原生 JavaScript 和 Manifest V3，无需安装依赖或构建。可在 Chrome 和基于 Chromium 的 Microsoft Edge 中以开发者模式加载；实际播放效果需在各浏览器中验证。

## 功能

- **通用扫描**：识别 `<audio>` 音源及 MP3、M4A、OGG、OGA、WAV、FLAC、AAC、OPUS、WEBM 直接链接，格式支持取决于浏览器。
- **按需启用**：点击工具栏图标在其他网站启用，动态音源加载后可重新扫描。
- **顺序循环**：按页面顺序逐首播放，队列结束后从头开始。
- **随机播放**：每轮歌曲不重复，跨轮避免连续播放同一首；只有一首歌时会重复播放。
- **播放控制**：暂停、继续、下一首、停止，以及进度和音量调节。
- **队列查看**：显示歌曲列表和当前曲目，收起面板后仍可播放。
- **失败处理**：音源请求或加载失败时跳过，连续整轮失败后停止。

## 安装

下载并解压项目，或克隆仓库到本地。加载时选择 **`extension` 文件夹**，其中应直接包含 `manifest.json`。

| 浏览器 | 扩展管理页面 | 操作 |
| --- | --- | --- |
| Google Chrome | `chrome://extensions/` | 开启「开发者模式」→「加载已解压的扩展程序」 |
| Microsoft Edge | `edge://extensions/` | 开启「开发人员模式」→「加载解压缩的扩展」 |

本地加载无需注册商店开发者账号，也无需支付应用商店注册费。

## 使用

### 通用模式

1. 在含有音频播放器或音频直接链接的普通 HTTP/HTTPS 网页，点击工具栏中的 **AutoPlayAll** 图标（可在扩展菜单中固定）。
2. 在右下角选择播放方式，点击「开始播放」。
3. 动态加载音频后可点击「重新扫描」；扫描会停止播放并重建队列。

通用模式先收集音频播放器的当前音源，再收集文件链接，按完整 URL 去重并保留签名查询参数。同一播放器的备用格式不会被当成多首歌曲。扫描仅覆盖当前页面主文档。

### 世纪音乐网适配

1. 安装后打开或刷新[示例歌曲页面](https://www.4c44.com/mp3/hekkmd.html)。如果网站出现人机验证，请手动完成。
2. 在网页右下角的「AutoPlayAll」面板中选择「顺序循环」或「随机不重复」。
3. 点击「开始播放」。扩展会暂停网页原播放器，使用面板内的音频控件播放。
4. 使用音频控件暂停、继续或调整进度；点击「下一首」切歌，点击「停止」结束播放。

队列在页面加载时生成：单曲页面以当前歌曲为首，然后加入页面内指向同源 `/mp3/*.html` 的歌曲链接，并按歌曲 ID 去重。队列数量以面板显示为准，推荐内容变化时数量也可能变化。

播放范围是**当前页面的歌曲链接**，不会递归收集其他页面的推荐内容、歌手全部歌曲或分页内容。保持标签页打开；刷新或导航到其他页面会重新生成队列。播放中切换随机模式会重组队列，当前曲目不加入该轮剩余歌曲。

## 工作原理

扩展通过内容脚本读取当前页面的歌曲信息，在独立的 Shadow DOM 面板中展示队列和原生音频控件。通用模式直接播放扫描到的音频地址；世纪音乐网适配在切歌时向本站 `/js/play.php` 请求最新音源地址。

| 文件 | 职责 |
| --- | --- |
| `extension/manifest.json` | Manifest V3 配置及运行域名 |
| `extension/engine.js` | 歌曲提取、队列调度、播放状态和请求参数 |
| `extension/content.js` | 页面面板、音源请求和音频事件处理 |
| `extension/background.js` | 响应工具栏点击并注入当前页 |
| `tests/generic.test.cjs` | 音频识别、队列及工具栏启用测试 |
| `extension/使用说明.md` | 面向安装用户的使用说明 |
| `docs/implementation.md` | 实现范围和设计记录 |
| `LICENSE` | MIT 许可证全文 |

## 本地开发与检查

直接编辑 `extension` 下的文件。修改后在浏览器扩展管理页重新加载扩展，再刷新歌曲页面。

如已安装 Node.js，可在项目根目录进行 JavaScript 语法检查，无需 `npm install`：

```sh
node --check extension/engine.js
node --check extension/content.js
node --check extension/background.js
node --test tests/generic.test.cjs
```

自动化测试覆盖通用音源提取、去重、域名隔离、队列切换及工具栏启用；不能代替真实音频播放验证。提交变更前，请在浏览器中检查：

- 页面歌曲数量及顺序正确，同一歌曲链接不会重复加入。
- 当前歌曲结束后自动切换，顺序模式能在队列末尾回到开头。
- 随机模式每轮无重复，切换模式后仍可继续播放。
- 暂停、继续、下一首、停止及收起面板工作正常。
- 请求未完成时停止播放，不会在请求返回后突然播放。
- 音源不可用或人机验证失效时，能跳过歌曲或停止并提示。

## 常见问题与限制

**没有出现面板？**

其他网站需点击工具栏图标。世纪音乐网的 HTTPS 页面保留自动启用。浏览器内部页面及扩展商店等受限页面无法注入脚本，图标会显示「!」。安装或更新后请重新加载扩展并刷新网页。

**通用模式能播放所有网站的歌单吗？**

只能识别主文档已暴露的音频地址，不会自动点击歌单或调用未知网站的私有接口。不支持 iframe、Shadow DOM 内部音频、Blob/MediaSource、DRM 及 HLS/DASH 清单。CSP、防盗链、登录状态、浏览器混合内容限制和音源有效期可能影响播放；此类网站可能仍需专用适配。

**点击开始后没有声音？**

浏览器可能拦截自动播放，请点击面板内音频控件的播放按钮。检查音量，并确认原站音源能正常播放。

**歌曲不断跳过或全部加载失败？**

确认网站验证仍有效、网络和原站音源可用。请求参数依赖电脑本地时间，请保持系统时间准确；停止后可重新开始。本站接口、页面结构或音源服务变化都可能导致适配失效。

**关闭面板或标签页后会怎样？**

「收起」仅折叠面板，不影响播放；「停止」结束播放。关闭标签页会停止播放，当前版本没有跨页面恢复或队列持久化功能。

**兼容性验证到什么程度？**

实现依据此前保存的真实页面及播放器脚本。Chrome 和 Edge 中的已安装扩展尚未完成真实音频端到端验证；提交问题时请说明浏览器版本、页面网址和复现步骤。

## 权限与隐私

通用模式使用 `activeTab` 和 `scripting`，点击工具栏图标后访问当前页并注入扫描脚本；世纪音乐网仍按限定域名自动启用。没有申请所有网站的永久访问权限，也未申请浏览历史、下载或存储权限。队列和状态只保存在页面内存中，没有统计追踪或开发者数据接收服务。

通用模式通过浏览器连接音源服务器；世纪音乐网适配会携带本站会话向本站接口请求歌曲地址。这些服务会接收正常网络请求所需的信息；扩展自身不持久保存或向开发者发送页面内容与播放记录。
