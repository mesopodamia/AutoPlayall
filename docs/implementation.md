# AutoPlayAll 页面歌曲播放器

## 1.1.0 通用模式

其他网站通过工具栏点击临时授权，使用 activeTab + scripting 注入当前主文档，不申请所有网站永久权限。世纪音乐网保留自动启用和既有接口适配。

通用扫描按 audio 当前音源、src 或一个可用 source 提取歌曲，然后加入常见扩展名的直接音频链接；解析相对路径，保留查询参数，过滤非 HTTP/HTTPS 地址并去重。重新扫描会停止播放并替换整个队列。随机与顺序播放共用现有引擎。

运行 `node --test tests/generic.test.cjs` 验证扫描、去重、格式备选、域名隔离、队列、停止取消及工具栏启用。浏览器真实播放尚需现场验证。iframe、Shadow DOM、Blob/DRM、HLS/DASH 和私有接口歌单不在通用模式范围内。

## 原始网站适配

范围：当前歌曲和当前页面所有 /mp3/*.html 链接，去重后保持页面顺序；不递归扩展其他页面。顺序循环；随机模式每轮无重复，跨轮不连续重复。用户点击开始后接管播放，保留页面原播放器但暂停它。

实现步骤：
1. 使用 Node 内置测试先验证队列、随机轮次、结束切歌和拒绝自动播放的行为。
2. 实现独立播放引擎，以及读取当前页面链接、调用本站播放接口的内容脚本。
3. 添加 Manifest V3 和页面控制面板（原生音频控件、模式、开始、下一首、停止）。
4. 执行测试、语法和 manifest 检查，生成只包含插件文件的 ZIP，附安装说明。

验证边界：已保存 HTML 和 player.js 可验证本站结构与接口协议；实时网站人机验证、音源可用性和浏览器自动播放策略需要安装后现场验证。
